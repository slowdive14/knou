# KNOU 형성평가 자동화 및 강의 노트 정리 — 사용 설명서 (비개발자용)

방송대(KNOU) 강의 영상을 **자동 이수**하고, 강의를 **예습 노트(옵시디언)** 로
정리해 주는 데스크톱 앱입니다. 검은 명령창을 다룰 필요 없이 **창에서 클릭**으로
씁니다.

> ⚠️ **중요** — '이수/전체' 모드는 형성평가(연습문제) 답안을 **실제 서버에 제출**합니다.
> 이 제출은 **되돌릴 수 없습니다.** 본인 계정·예습 목적일 때만 사용하세요.
> 실행 전 앱이 확인 창을 띄웁니다.

---

## 1. 준비물 (처음 한 번만)

| 필요한 것 | 설명 |
|---|---|
| **Python 3.11+** | [python.org](https://www.python.org/downloads/) 에서 설치. 설치 화면에서 **"Add Python to PATH" 체크**. |
| **ffmpeg** | 영상→오디오 변환용. [ffmpeg.org](https://ffmpeg.org/download.html) 에서 받아 PATH 에 추가하거나, 프로젝트 폴더에 `ffmpeg.exe`/`ffprobe.exe` 를 둡니다. |
| **Gemini API 키** | 강의 요약(무료 키 가능). [Google AI Studio](https://aistudio.google.com/apikey) 에서 발급. |
| **인터넷 연결** | 로그인·영상 시청·요약에 필요. |

---

## 2. 설치 (처음 한 번만)

### 가장 쉬운 방법 — 설치 도우미 더블클릭 (권장)

1. 먼저 [python.org](https://www.python.org/downloads/) 에서 파이썬을 설치합니다.
   설치 **첫 화면에서 "Add Python to PATH" 체크**를 잊지 마세요.
2. 이 폴더의 **`install.bat` 을 더블클릭**합니다.
3. 까만 창에서 `[1/4] … [4/4] …` 가 차례로 지나가고, **"설치 완료!"** 가 보이면 끝입니다.
   (인터넷 속도에 따라 몇 분 걸립니다. 중간에 창을 닫지 마세요.)

> 까만 창에 빨간/영문 오류가 보이면, 인터넷 연결을 확인하고 `install.bat` 을 한 번 더 더블클릭해 보세요.
> 그래도 안 되면 아래 *수동 설치* 를 따라 하거나 7번 *문제가 생기면* 표를 참고하세요.

### 수동 설치 (도우미가 안 될 때만)

프로젝트 폴더에서 명령창(PowerShell)을 열고 아래를 **한 줄씩** 실행합니다.
(폴더 빈 공간에서 **Shift + 마우스 우클릭 → "여기에 PowerShell 창 열기"**)

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m playwright install chromium
```

- 첫 줄: 전용 파이썬 환경(`.venv`) 생성
- 둘째 줄: 필요한 라이브러리 설치
- 셋째 줄: 영상 시청용 브라우저(크로미움) 설치

### ffmpeg 설치 (영상→오디오 변환용)

가장 쉬운 방법은 PowerShell 에서 아래 한 줄을 실행하는 것입니다.

```powershell
winget install Gyan.FFmpeg
```

winget 이 없거나 막히면, [ffmpeg.org](https://ffmpeg.org/download.html) 에서 받은
`ffmpeg.exe`·`ffprobe.exe` 두 파일을 **이 프로젝트 폴더에 복사**해 넣으세요.

설치는 처음 한 번이면 됩니다.

---

## 3. 앱 켜기

방법 ① **`run_app.bat` 더블클릭** — 가장 간단합니다.

방법 ② **바탕화면 바로가기** (콘솔 창 없이 깔끔하게 열림) — 앱을 한 번 켠 뒤
**설정 탭 → [바탕화면 바로가기 만들기]** 를 누르면 바탕화면에
`KNOU 강의 자동화` 바로가기가 생깁니다. 다음부터 그걸 더블클릭하세요.

---

## 4. 첫 설정

앱을 처음 켜면 **설정** 화면이 먼저 뜹니다. 별표(*) 항목을 채우고 **[저장]**:

- **방송대 아이디 / 비밀번호** * — 로그인용 (비밀번호는 화면에서 가려지고 로그에 남지 않습니다)
- **Gemini API 키** * — 강의 요약용
- **옵시디언 볼트 경로** * — 노트를 저장할 폴더 (예: `G:\내 드라이브\...\방송대예습`)
- 노트 저장 하위폴더 / 영상 재생 배속 — 선택 (배속은 0.5~2.0)

> 입력값은 프로젝트 폴더의 `.env` 파일에만 저장됩니다. 화면·로그 어디에도
> 비밀번호·API 키가 평문으로 보이지 않습니다.

## 5. 사용법

### 실행 탭 — 지금 바로 돌리기
1. **모드** 선택
   - **요약**: 영상 제출 없이 **예습 노트만** 생성 (안전)
   - **이수**: 영상 시청 + **형성평가 자동 제출** (되돌릴 수 없음)
   - **전체**: 이수 + 요약
2. (선택) 과목·차시로 범위 좁히기
3. **[실행]** → 진행 로그가 화면에 흐릅니다. '이수/전체'는 확인 창이 한 번 뜹니다.

### 예약 탭 — 정해진 시각에 자동 실행
- 모드·시각(예: `02:00`)·반복(매일/한 번)을 정해 **[예약 추가]**.
- 앱·터미널이 꺼져 있어도 그 시각에 자동 실행됩니다(**창은 뜨지 않습니다**).
- 등록된 예약 줄에서 **[끄기]/[켜기]** 로 잠시 멈추거나 재개, **[삭제]** 로 제거.
- 실행 결과는 **실행 탭 → [최근 실행 로그 보기]** 로 확인합니다.

> 매일(DAILY) 예약은 다음 날부터 지정 시각에 **매일 반복**됩니다.
> "다음 실행: N/A" 는 '한 번(ONCE)' 예약이 이미 지난 경우입니다.

---

## 6. 절전(잠자기) 관련

- 예약 자동 실행 중에는 앱이 **시스템 절전을 자동으로 막습니다**(실행 동안만 →
  영상이 멈춰 이수가 깨지지 않게). 끝나면 평소대로 절전됩니다. 모니터 화면이
  꺼지는 것은 괜찮습니다.
- 다만 **지정 시각 이전부터 PC가 이미 잠자기** 중이면 작업이 시작되지 않습니다.
  야간 실행을 쓰려면 그 시간엔 PC가 켜져 있게 하세요.

## 7. 문제가 생기면

| 증상 | 해결 |
|---|---|
| 앱이 안 열림 | `.venv` 가 있는지, 2번 설치를 마쳤는지 확인. `run_app.bat` 을 더블클릭하면 오류 메시지가 보입니다. |
| 영상/브라우저 오류 | `.venv\Scripts\python.exe -m playwright install chromium` 다시 실행. |
| ffmpeg 관련 오류 | ffmpeg/ffprobe 가 PATH 또는 프로젝트 폴더에 있는지 확인. |
| 로그인 실패 | 설정 탭에서 아이디·비밀번호를 다시 저장. |
| 자세한 실행 기록 | 프로젝트 폴더의 `logs\run_*.log` (또는 실행 탭의 '최근 실행 로그 보기'). |

## 8. 안전·개인정보 요약

- 비밀번호·API 키는 **`.env` 에만** 저장(화면 마스킹, 로그·콘솔 평문 출력 안 함).
- 형성평가 **자동 제출은 되돌릴 수 없음** → 실행 전 확인 창.
- 강의 영상 캡처 프레임 등 대용량·개인 자료는 git 에 올라가지 않습니다(`.gitignore`).
