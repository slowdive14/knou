# KNOU 강의 이수 + 예습 노트 — 사용 설명서 (비개발자용)

방송대(KNOU) 강의를 **자동으로 이수**하고, 강의를 **예습 노트(옵시디언)** 로 정리해 주는 데스크톱 앱입니다. 모은 문제와 기출문제를 다시 풀고, 목표일까지의 진도도 관리합니다. 검은 명령창을 다룰 필요 없이 **창에서 클릭**으로 씁니다.

> ⚠️ **중요**: '이수'·'전체' 모드와 [형성평가만 실행] 은 **실제 방송대 서버에 시청 기록을 남기고 돌발퀴즈·형성평가 답안을 제출합니다.** 본인 계정에 반영되며 되돌릴 수 없으니, 본인 계정·학습 목적일 때만 쓰세요. 실행 전에 앱이 확인 창을 띄웁니다.

## 1. 준비물 (처음 한 번)

| 필요한 것 | 설명 |
|---|---|
| **Python 3.11 이상** | [python.org](https://www.python.org/downloads/) 에서 설치합니다. 설치 화면에서 **"Add Python to PATH"** 를 체크하세요 |
| **Gemini API 키** | 노트·해설을 만드는 AI 입니다. [Google AI Studio](https://aistudio.google.com/apikey) 에서 무료로 발급합니다 |
| **ffmpeg** *(선택)* | 노트에 **슬라이드 그림**을 넣거나, MP3 가 없는 과목의 음성을 영상에서 뽑을 때 필요합니다. 없어도 글로 된 노트는 만들어집니다 |
| **옵시디언** *(권장)* | 노트를 보는 프로그램입니다. 노트 칩을 누르면 옵시디언에서 열립니다 |
| **인터넷 연결** | 로그인·이수·노트 만들기에 필요합니다 |

## 2. 설치 (처음 한 번)

### 가장 쉬운 방법: 설치 도우미 (권장)

1. [python.org](https://www.python.org/downloads/) 에서 파이썬을 설치합니다. 첫 화면에서 **"Add Python to PATH"** 체크를 잊지 마세요.
2. 이 폴더의 **`install.bat`** 을 더블클릭합니다.
3. 까만 창에 `[1/4] … [4/4]` 가 차례로 지나가고 **"설치 완료!"** 가 보이면 끝입니다. 몇 분 걸리니 중간에 창을 닫지 마세요.

> 빨간 오류가 보이면 인터넷 연결을 확인하고 `install.bat` 을 한 번 더 더블클릭하세요. 그래도 안 되면 아래 *수동 설치* 를 따라 하거나 7번 표를 보세요.

### 수동 설치 (도우미가 안 될 때만)

폴더 빈 공간에서 **Shift + 마우스 오른쪽 클릭 → "여기에 PowerShell 창 열기"** 를 누르고, 아래를 한 줄씩 실행합니다.

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m playwright install chromium
```

첫 줄은 전용 파이썬 환경(`.venv`)을 만들고, 둘째 줄은 필요한 프로그램을 설치하고, 셋째 줄은 학교 사이트를 여는 브라우저를 설치합니다.

### (선택) ffmpeg 설치

처음에는 건너뛰고 나중에 설치해도 됩니다. PowerShell 에서 아래 한 줄을 실행하세요.

```powershell
winget install Gyan.FFmpeg
```

winget 이 없거나 막히면, [ffmpeg.org](https://ffmpeg.org/download.html) 에서 받은 `ffmpeg.exe`·`ffprobe.exe` 두 파일을 이 폴더에 복사해 넣으세요.

## 3. 앱 켜기

- **방법 ①** `run_app.bat` 을 더블클릭합니다.
- **방법 ②** 바탕화면 바로가기: 앱을 한 번 켠 뒤 **설정 탭 → [바탕화면 바로가기 만들기]** 를 누르면 바탕화면에 `KNOU 강의 자동화` 아이콘이 생깁니다. 다음부터 그것을 더블클릭하면 검은 창 없이 앱만 뜹니다.

## 4. 첫 설정

앱을 처음 켜면 **설정** 화면이 먼저 뜹니다. 별표(*) 항목을 채우고 **[저장]** 을 누르세요.

| 항목 | 설명 |
|---|---|
| 방송대 아이디 / 비밀번호 * | 로그인용. 비밀번호는 화면에서 가려지고 기록에 남지 않습니다 |
| Gemini API 키 * | 노트·해설을 만들 때 씁니다 |
| 볼트 경로 * | 노트를 저장할 옵시디언 볼트 폴더(예: `G:\내 드라이브\…\방송대예습`) |
| 요약 폴더 | 볼트 안에서 노트를 둘 폴더(비우면 `방송대`) |
| 영상 재생 배속 | 이수할 때 배속, 0.5~2.0(기본 2.0) |

> 입력값은 이 폴더의 `.env` 파일에만 저장됩니다. 화면과 기록 어디에도 비밀번호·API 키가 그대로 보이지 않습니다.

## 5. 탭별 사용법

왼쪽 메뉴에서 탭을 고릅니다. 메뉴 맨 아래 밝기 단추를 누르면 **시스템 → 밝게 → 어둡게** 로 바뀝니다.

### 실행 탭: 지금 바로 돌리기

1. **모드**를 고릅니다.
   - **요약**: 서버에 아무것도 남기지 않고 **예습 노트만** 만듭니다(가장 안전).
   - **이수**: 영상 시청 + 돌발퀴즈 + **형성평가 자동 풀이**(서버 제출, 되돌릴 수 없음).
   - **전체**: 이수 + 요약.
2. **과목**과 **차시**를 고릅니다. 차시를 비우면 **'한 번에 최대 N강'** 만큼 차례로 돌고, **'미이수부터'** 를 켜면 아직 안 본 강의만 돕니다.
3. **[실행]** 을 누르면 진행 로그가 화면에 흐릅니다. 이수·전체는 확인 창이 한 번 뜹니다.
4. 끝나면 **[노트 열기]** 로 만든 노트를 옵시디언에서 엽니다. 그 차시에 영상이 하나 더 있으면 "두 번째 영상도 노트를 만들까요?" 하고 묻습니다.

다른 단추들:

| 단추 | 쓰는 때 |
|---|---|
| **[영상 이수만 실행]** | 노트는 있는데 이수만 안 된 차시 |
| **[형성평가만 실행]** | 형성평가만 다시 풀어 문제를 모을 때(서버 제출, 확인 창) |
| **[강의록만 받기]** | 강의록만 빠진 차시 |
| **이미 만든 것도 다시 만들기** | 이미 끝난 노트·단계를 처음부터 다시 만들 때 |
| **[최근 실행 로그 보기]** | 예약 실행 결과를 볼 때 |
| **[퀴즈 페이지 만들기]** · **[학습 현황 페이지]** | 퀴즈·현황을 HTML 파일로 저장해 브라우저에서 볼 때 |

> 실패해도 걱정하지 않아도 됩니다. 그대로 다시 실행하면 성공한 단계는 건너뛰고 **실패한 곳부터** 이어서 합니다.

### 현황 탭: 무엇이 다 됐나

과목·차시마다 **영상이수 · 형성평가 · 예습노트 · MP3 · 강의록**이 있는지 표로 봅니다.

- 노트 칩은 **옵시디언**에서, 강의록은 **앱 안**에서, MP3 는 윈도우 기본 프로그램에서 열립니다.
- 강의록이 비어 있는 줄의 내려받기 아이콘을 누르면 그 강의록만 받습니다.
- 형성평가 칸의 `4문항` 칩을 누르면 퀴즈 탭의 그 강의로 갑니다.
- **[남은 것만 보기]** 로 아직 안 끝난 차시만 봅니다.

### 진도 탭: 목표일까지 다 보기

목표일까지 모든 강의를 한 번씩 보는 것을 돕습니다.

1. 처음에는 **[과목 불러오기]** 를 눌러 과목과 강의 수를 가져옵니다.
2. 강의를 들으면 그 과목의 **강 번호 칸을 누릅니다.** 잘못 눌렀으면 다시 눌러 뺍니다.
3. 맨 위에 **남은 날과 하루·한 주 몫**, 오늘·이번 주에 본 양이 나옵니다. 계획보다 늦으면 어느 과목부터 볼지 알려 줍니다.
4. 과목 카드는 **가장 오래 손을 놓은 과목이 맨 위**에 오고, 최근에 들은 날이 적힙니다(7일이 넘으면 귤색, 14일이 넘으면 빨간색).

목표일은 위쪽 칸에서 바꾸고 **[적용]** 을 누릅니다. 단톡방 공부 인증을 한꺼번에 채우려면 **도구 탭 → '카카오톡 인증 기록 불러오기'** 를 쓰세요.

### 퀴즈 탭: 다시 풀기

이수할 때 푼 돌발퀴즈·형성평가와 기출문제를 다시 풉니다.

1. 위쪽에서 **강의(문제 묶음)** 를 고르거나, **'강 모아보기'** 로 회차를 가리지 않고 그 강의 문제만 모읍니다.
2. 보기를 누르면 맞았는지 바로 보입니다. **[정답 보기]** 로 정답을 확인합니다.
3. **[왜 이게 정답인지 설명 보기]** 를 누르면 AI 해설이 나옵니다. 그래도 모르겠으면 **물어보기**로 되물을 수 있습니다(창이 넓으면 오른쪽에 대화 창이 붙습니다).
4. 출제 모드: **[전체]**(틀린 것부터) · **[오답만]** · **[안 푼 것만]** · **[복습할 것]**.

- 문제마다 '안 푼 문제' · '3번 풀어 2번 맞힘' 같은 표지가 붙습니다.
- **[현재 강 초기화]** · **[전체 초기화]** 로 풀이 기록을 지웁니다.
- **[기출 더 가져오기]** 를 누르면 지금 과목의 강의자료실에서 아직 안 담은 기출 회차를 가져옵니다.
- **'기출 원본'** 줄에서 회차마다 **[시험지] [정답표]** 를 눌러 원래 파일을 엽니다. 문제가 이상해 보일 때 대 보세요.
- 창이 작으면 위쪽 메뉴가 한 줄로 접힙니다. **[메뉴 펼치기]** 로 다시 엽니다.

### 예약 탭: 정해진 시각에 자동 실행

1. 모드·과목·시각(예: `02:00`)·반복(매일 / 한 번)을 정합니다.
2. **'한 번에 최대 (강)'** 은 기본 **3강**을 권합니다. 비우면 남은 강의를 전부 돌려 12시간 넘게 걸릴 수 있습니다.
3. **[예약 추가]** 를 누릅니다. 앱이 꺼져 있어도 그 시각에 창 없이 실행됩니다.

| 단추 | 하는 일 |
|---|---|
| **[지금 멈추기]** | 지금 돌고 있는 실행을 바로 멈춥니다 |
| **[끄기] / [켜기]** | 다음 실행부터 막거나 다시 엽니다 |
| **[삭제]** | 예약을 지웁니다 |

실행 결과는 **실행 탭 → [최근 실행 로그 보기]** 로 확인합니다.

### 도구 탭: 가끔 하는 일

가끔 필요한 일을 명령어 없이 실행합니다. 도구마다 **'이럴 때'** 와 **'하는 일'** 이 적혀 있으니 읽어 보고, 칸을 채운 뒤 **[실행]** 을 누르세요. 진행 상황은 오른쪽 기록판에 나오고, 다른 탭에 다녀와도 계속 돕니다.

| 이럴 때 | 도구 |
|---|---|
| 퀴즈의 '기출 원본' 에서 [시험지] 가 흐리게 나올 때 | 시험지 회차 읽기 |
| 자료실에 없는 기출 시험지를 따로 구했을 때 | 건네받은 시험지로 회차 만들기 |
| 기출 문제가 시험지와 달라 보일 때 | 기출 문항 확인·바로잡기 |
| '아래 그림은…' 인데 그림이 없을 때 | 기출 그림 붙이기 |
| '강 모아보기' 에 새 기출이 안 나올 때 | 기출에 강 번호 붙이기 |
| 기출 답이 외워졌을 때 | 변형 문제 만들기 · 변형 문제 검토 |
| 형성평가 문제에 지문이 빠졌을 때 | 빠진 형성평가 지문 채우기 |
| 강의록 다운로드가 실패해 따로 모아 둔 PDF 가 있을 때 | 손에 있는 강의록 들여오기 |
| 바이오통계학 노트를 처음 만들 때 | 바이오통계학 슬라이드 받기 → 손에 있는 강의록 들여오기 |
| 노트 그림 크기가 들쭉날쭉할 때 | 노트 그림 폭 맞추기 |
| 단톡방 인증을 진도 탭에 채울 때 | 카카오톡 인증 기록 불러오기 |

> 'C 컴파일러 설치' 처럼 컴퓨터에 프로그램을 까는 일은 앱이 대신하지 않습니다. 파일 위치를 열어 주니 직접 더블클릭하세요.

## 6. 절전(잠자기)

- 실행하는 동안 앱이 **절전을 자동으로 막습니다**(앱에서 누른 실행과 예약 실행 모두). 끝나면 평소대로 돌아갑니다. 모니터가 꺼지는 것은 괜찮습니다.
- **노트북 뚜껑을 닫으면 그래도 잠듭니다.** 뚜껑을 닫고 돌리려면 제어판 → 전원 옵션 → '덮개를 닫을 때 수행할 작업' 을 **아무 것도 안 함** 으로 바꾸세요.
- 예약 화면의 **'절전 중이면 PC를 깨워서 실행'** 을 켜면 잠든 PC를 깨워 실행합니다. Windows 설정 때문에 깨어나지 않으면 앱이 바꿀 방법을 안내합니다.
- 깨우기를 켜지 않았거나 PC가 꺼져 있었다면, **다음에 PC를 켤 때** 밀린 예약이 실행됩니다.

## 7. 문제가 생기면

| 증상 | 해결 |
|---|---|
| 앱이 안 열림 | 2번 설치를 마쳤는지(`.venv` 폴더가 있는지) 확인하세요. `run_app.bat` 을 더블클릭하면 오류 메시지가 보입니다 |
| 브라우저 오류 | 수동 설치의 셋째 줄(`playwright install chromium`)을 다시 실행하세요 |
| 로그인 실패 | 설정 탭에서 아이디·비밀번호를 다시 저장하세요. 학교가 **추가 인증(인증번호 등)** 을 요구하면 자동 로그인이 멈추고 로그에 이유가 남습니다. 브라우저에서 한 번 직접 로그인해 주세요 |
| AI 오류(붐빔·모델 없음) | 앱이 다른 모델로 저절로 넘어갑니다. 계속 실패하면 잠시 뒤 다시 실행하세요 |
| 노트에 그림이 없음 | ffmpeg 를 설치했는지 확인하세요. 그 강의를 요약 모드로 다시 실행하면 그림만 다시 붙습니다 |
| 노트가 안 만들어짐(바이오통계학) | 도구 탭의 '바이오통계학 슬라이드 받기' 와 '손에 있는 강의록 들여오기' 를 먼저 하세요 |
| 실행 끝에 '강의 목록 갱신 실패(무시)' | 실행 결과에는 영향이 없습니다. 실행 탭의 [목록 새로고침] 으로 목록을 다시 받을 수 있습니다 |
| 자세한 실행 기록 | 이 폴더의 `logs\run_*.log`, 또는 실행 탭의 [최근 실행 로그 보기] |

## 8. 안전·개인정보

- 비밀번호·API 키는 **`.env` 에만** 저장됩니다(화면에서 가리고, 기록에 평문으로 남기지 않음).

- 강의 화면 캡처, 내려받은 자료, 로그 같은 개인 자료는 git 에 올라가지 않습니다.
