# KNOU 강의 이수 + 예습 노트

방송대(KNOU) 강의 영상을 **자동으로 이수**하고, 강의를 **예습 노트(옵시디언 마크다운)** 로
정리해 주는 **Windows 데스크톱 앱**입니다. 검은 명령창을 다룰 줄 몰라도 **창에서 클릭**으로 씁니다.

- 🎬 강의 영상 자동 시청(이수) + 영상 중 돌발퀴즈 + 형성평가(연습문제) 자동 풀이
- 📝 강의를 듣고 **예습 노트** 자동 생성 — 타임스탬프(🎬)와 강의 슬라이드 이미지 포함
- 🧩 풀었던 **돌발퀴즈·형성평가를 모아 다시 풀어보는 복습 HTML 페이지** 생성
- ⏰ 새벽 시간 등 **예약 자동 실행**(앱이 꺼져 있어도, 창도 안 뜸)

> [!WARNING]
> **개인 학습용 도구입니다. 반드시 본인 방송대 계정으로만 사용하세요.**
> '이수/전체' 모드는 **실제 방송대 서버에 영상 시청(이수) 기록을 남기고, 돌발퀴즈와
> 형성평가(연습문제) 답안을 자동 제출합니다.** 본인 계정에 반영되며 **되돌릴 수 없으므로**
> 앱이 실행 전 확인 창을 띄웁니다. 처음에는 서버에 아무것도 남기지 않는 **'요약' 모드**부터
> 써 보길 권합니다.

## 🚀 빠른 시작 (3단계)

### 1) 설치 (처음 한 번만) — 명령어 몰라도 됩니다

**① 파이썬 설치**
[python.org](https://www.python.org/downloads/) 에서 노란 **[Download]** 버튼을 눌러 설치하세요.
⚠️ 설치 **첫 화면 맨 아래 "Add Python to PATH" 를 꼭 체크**한 뒤 설치하세요.

**② 설치 도우미 더블클릭**
이 폴더의 **`install.bat` 을 더블클릭**하세요. 까만 창이 뜨면서 필요한 것을 알아서 설치합니다
(몇 분 걸립니다). **"설치 완료!"** 가 보이면 끝 — 창을 닫으세요.

> 명령어를 직접 치고 싶다면(또는 도우미가 안 될 때) → [README_GUI.md](README_GUI.md) 의 *수동 설치* 참고.

**③ (선택) ffmpeg 설치** — 노트에 **강의 슬라이드 이미지**까지 넣고 싶을 때만 필요합니다.
없어도 텍스트 예습 노트는 정상 생성되니, **처음엔 건너뛰고 나중에 설치**해도 됩니다.
설치하려면 시작 메뉴에서 **PowerShell** 을 열고 아래 한 줄을 붙여넣어 실행하세요.

```powershell
winget install Gyan.FFmpeg
```

(winget 이 없거나 막히면, [ffmpeg.org](https://ffmpeg.org/download.html) 에서 받은
`ffmpeg.exe`·`ffprobe.exe` 두 파일을 **이 프로젝트 폴더에 그대로 복사**해 넣어도 됩니다.)

### 2) 실행
폴더의 **`run_app.bat` 더블클릭** → 앱 창이 뜹니다.
(앱의 **설정 탭 → [바탕화면 바로가기 만들기]** 를 누르면, 다음부터는 바탕화면 아이콘으로
**검은 창 없이** 깔끔하게 켤 수 있습니다.)

### 3) 설정
**설정** 화면에서 별표(*) 항목을 채우고 **[저장]**:
- 방송대 **아이디 / 비밀번호** *
- **Gemini API 키** * — [Google AI Studio](https://aistudio.google.com/apikey) 에서 무료 발급
- **옵시디언 볼트 경로** * — 노트를 저장할 폴더

이제 **실행** 탭에서 강의를 골라 돌리거나, **예약** 탭에서 자동 실행을 걸면 됩니다.

📖 **자세한 사용법·문제 해결은 [README_GUI.md](README_GUI.md) 를 보세요.**

### 모드
- **요약** — 서버에 아무것도 안 남기고 **예습 노트만** 생성 (가장 안전, 추천 시작점)
- **이수** — 영상 시청 + 돌발퀴즈 + **형성평가 자동 풀이** (실제 서버 제출, 되돌릴 수 없음)
- **전체** — 이수 + 요약

### 한 번에 몇 강까지 (실행 탭)

**차시**를 고르면 그 한 강만 돕니다(개수는 무시). **차시를 비우면** '한 번에 최대 (강)' 개수만큼 차례로 돕니다 — 이때 **미이수부터** 체크가 켜져 있으면 아직 안 본 차시만 대상으로 삼습니다.

예약 탭의 같은 칸과 규칙이 같습니다. 여러 강을 한 번에 돌리면 '노트 열기' 버튼과 두 번째 영상 확인은 뜨지 않습니다(어느 강인지 특정할 수 없어서).

### 영상 이수만 따로 실행

실행 탭의 **[영상 이수만 실행]** 은 선택한 차시의 **영상만** 다시 이수합니다(형성평가·예습노트는 건드리지 않음). 예습노트는 LMS가 주는 MP3로 만들기 때문에 **노트는 멀쩡한데 이수만 안 된 차시**가 생기는데, 그때 '덮어쓰기'로 전체를 다시 돌리면 노트까지 새로 만들어 Gemini 사용량만 낭비합니다.

현황 화면에서 **주황색 '실행함'** 이 붙은 줄이 이 버튼의 대상입니다. 이미 완료로 기록된 차시도 덮어쓰기로 다시 시도합니다.

### 형성평가만 따로 실행

실행 탭의 **[형성평가만 실행]** 은 선택한 차시의 **형성평가만** 다시 풀어 퀴즈 문항을 모읍니다(영상 이수·노트 생성은 하지 않음). 실제 서버 제출이므로 동의 확인을 거칩니다.

이미 완료로 기록된 차시도 **덮어쓰기로 다시 시도**합니다. 형성평가가 늦게 뜨는 바람에 한 번 ‘없음’으로 기록되면 보통 실행에서는 영영 건너뛰어지기 때문에, 그 상태를 되돌리는 통로입니다.

### 강의 MP3가 없는 과목

일부 과목(예: AI네이티브가되기위한기초소양)은 LMS에 **음성 다운로드 링크가 비어** 있습니다. 영상과 강의록은 멀쩡히 있는데도 예전에는 노트가 아예 안 만들어졌습니다. 이제 두 단계로 구합니다:

1. **영상에서 오디오만 추출** (ffmpeg · HLS) → 다른 과목과 **같은 품질**의 노트. 51분 강의 기준 몇 분 걸립니다.
2. 그것도 안 되면 **강의록(PDF)만으로 요약** — 이때는 음성이 없으므로 `🎬 [HH:MM:SS]` 마커를 넣지 않고 `(교재 p.N)` 페이지 표시만 씁니다. 없는 강의 내용을 지어내지 말라는 지시도 함께 들어갑니다.

### 실패하면 그 지점부터 이어서 합니다

단계마다 성공 여부가 `state.json`에 기록되므로, **그대로 다시 실행하면 성공한 단계는 건너뛰고 실패한 단계부터** 이어서 합니다. 51분짜리 영상 이수를 마친 뒤 요약이 API 오류로 실패했다면, 다시 실행해도 영상은 다시 보지 않고 요약부터 재시도합니다.

> **'미이수부터'와 함께 쓸 때**: 영상 이수를 마친 강의는 LMS상 이수 완료가 되어 이 필터에 걸러지지만, **실패 기록이 남은 강의는 예외로 통과시킵니다.** 그렇지 않으면 "이수는 됐는데 노트가 실패한" 강의를 영영 이어서 할 수 없습니다.

**처리 순서**는 이어서 할 것을 앞으로 당깁니다 — 실패 기록이 있는 강의가 새 강의보다 먼저이고, 그 안에서는 **앞 단계가 비어 있는 것부터**입니다(노트가 없는 강의 → 이미지만 없는 강의). 한 번에 1강만 도는 설정에서 급한 것이 뒤로 밀리지 않게 하기 위함입니다. 실패 기록이 없으면 예전처럼 차시 순입니다.

전부 처음부터 다시 하려면 **[이미 만든 것도 다시 만들기(덮어쓰기)]** 를 켜세요.

### 한 단계가 실패해도 나머지는 진행됩니다

예전에는 단계 하나가 실패하면 **그 뒤 단계가 통째로 취소**됐습니다. 이제는 산출물이 없어 정말 못 도는 단계만 건너뜁니다:

| 실패한 단계 | 건너뛰는 단계 | 그대로 진행 |
|---|---|---|
| 덱 추출(capture) | 없음 | — |
| 형성평가(exam) | 없음 | 다운로드·요약·덱 추출 |
| 다운로드(download) | 요약·덱 추출 | 영상 이수·형성평가 |
| 요약(summarize) | 덱 추출 | 영상 이수·형성평가·다운로드 |

## 📊 학습 현황 한눈에 보기

**현황** 탭을 열면 앱 창 안에서 바로 보입니다(브라우저 창이 따로 뜨지 않습니다).
같은 내용을 파일로 두고 싶으면 **[HTML로 저장]** 으로 볼트에 `학습현황.html` 을 만들 수 있습니다.
과목별 표 한 장에 **차시마다** 다음이 나란히 놓입니다:

| 열 | 내용 |
|---|---|
| **차시** | 01 · 제목 · 진도(시청/전체 분, 본 시간이 있으면 막대로) |
| **영상이수** | 완료 / 실행함<sup>*</sup>(목록 새로고침 전) / 실행했지만 서버는 미완료 / · |
| **형성평가** 상태 | 위와 같되, 그 차시에 형성평가가 **아예 없으면 회색 `없음`** — 주황 경고와 구분됩니다 |
| **형성평가** | 완료 표시 + `4문항` 칩 (누르면 퀴즈 복습 페이지) |
| **예습노트** | 노트 칩 (두 번째 영상 노트가 있으면 `2` 칩도) |
| **MP3** | 강의 음성 |
| **강의록** | PDF · PPT · 한글 |

- 칩을 누르면 **각자 알맞은 곳에서 열립니다** — 아래 '무엇이 어디서 열리나' 참고.
- 위쪽 **[남은 것만 보기]** 로 아직 안 끝난 차시만 볼 수 있고(다 끝난 과목 카드는 통째로 숨김), 과목마다 진행 링과 `이수 1/15` 식 요약이 붙습니다.
- 앱의 **현황** 탭에는 **과목 칩**(전체 · 과목별)이 있어 스크롤 없이 한 번에 과목을 바꿉니다. 창을 좁히면 표가 자동으로 **접힌 배치**(차시 한 줄 + 있는 항목만 아랫줄)로 바뀌어 칸이 겹치지 않습니다.
- 크림 페이퍼 바탕에 민트(완료)·애프리콧(진행중) 액센트. 아이콘은 인라인 SVG라 외부 파일을 하나도 받지 않습니다.
- 오른쪽 위 **[시스템/밝게/어둡게]** 버튼으로 화면 밝기를 바꿉니다(누를 때마다 순환, 선택은 브라우저에 저장). 기본값 '시스템'은 윈도우·브라우저 설정을 따라가므로, 윈도우가 다크 모드면 처음엔 어둡게 열립니다.
- 이수 여부는 `lectures.json`(목록 스냅샷) 기준이라 **오래됐으면 '목록 새로고침' 후 다시 만드세요**. 페이지 상단에 목록을 받아온 시각이 적혀 있고, 스냅샷 이후에 실행한 차시는 ✅ 실행함<sup>*</sup> 로 구분됩니다.
- 로그인·네트워크 없이 **파일만 보고** 만들기 때문에 즉시 생성됩니다.

## 🖥 실행 중 검은 창이 안 뜹니다

한 강의를 처리하는 동안 ffmpeg·ffprobe가 수십~수백 번 실행됩니다(개념 16개 × 후보 프레임 6장이면 ffmpeg만 96번, 여기에 클립별 ffprobe까지). Windows는 콘솔 프로그램을 띄울 때마다 검은 창을 만드는데, 이 프로젝트는 모든 미디어 처리를 `proc_util.run_hidden`(= `CREATE_NO_WINDOW`)으로 돌려 **창이 전혀 뜨지 않습니다**. 로그는 그대로 파이프로 읽으므로 진행 상황은 앱 로그에 다 나옵니다.

앱 자체도 바탕화면 바로가기가 `pythonw.exe`로 띄우므로 콘솔 없이 창만 뜹니다. 터미널에서 직접 실행하면 당연히 그 터미널은 남습니다.

## 🎬 한 회차에 영상이 2개일 때 (자료구조 등)

- 방송대는 한 차시 안에 영상이 **1~3개** 들어가는 경우가 있는데, LMS 가 주는 MP3 는 회차당 1개뿐이라 기본 예습노트는 **본강의(가장 긴 영상) 하나**로 만들어집니다.
- 요약/전체 실행이 **끝난 뒤**, 그 회차에 5분 넘는 영상이 더 있으면 앱이 **"두 번째 영상도 예습노트를 만들까요?"** 하고 한 번 물어봅니다(안내·인트로용 짧은 클립은 묻지 않음).
- **[노트 만들기]** 를 누르면 두 번째 영상의 오디오만 뽑아 요약해 **별도 노트**로 저장합니다 — `{과목} {차시}강 - {차시명} (2).md`. 첫 노트는 건드리지 않습니다.
- **[건너뛰기]** 를 눌러도 기록은 남아 있어, 같은 차시를 다시 실행하면 또 물어봅니다.
- 명령줄로도 가능합니다: `python main.py --mode 요약 --course 자료구조 --seq 1 --stages extra`

## ⏰ 예약 & 절전

- 예약은 Windows 작업 스케줄러에 등록되어 **앱·터미널이 꺼져 있어도** 지정 시각에 실행됩니다(**창은 뜨지 않음**).
- 자동 실행 중에는 앱이 **시스템 절전을 자동으로 막아**(실행 동안만) 영상이 멈춰 이수가 깨지는 것을 방지합니다.

### 한 번에 몇 강까지 (중요)

**한 번에 최대 (강)** 을 비워두면 대상 강의를 **전부** 처리합니다. 15강이 모두 미이수인 과목을 '전체' 모드로 걸면 영상만 900분이 넘어 **한 번 실행이 12시간 이상** 이어집니다. 기본값 **3강**을 권합니다 — 남은 강의는 다음 날 실행이 이어서 처리하고, 이미 이수한 차시는 실행할 때마다 LMS를 다시 조회해 자동으로 빠집니다.

### 돌고 있는 예약 세우기

| 버튼 | 하는 일 |
|---|---|
| **지금 멈추기** | **지금 돌고 있는 실행을 즉시 중단** (`schtasks /End`) |
| **끄기** | 다음 실행부터 막음 — 이미 도는 것은 계속됩니다 |
| **삭제** | 예약을 완전히 제거 |

브라우저 창을 강제로 닫는 것으로는 멈추지 않습니다. 강의 하나가 실패해도 다음 강의로 넘어가며 창을 새로 열기 때문입니다.

> 이전 버전으로 등록한 예약은 실행기(VBS)가 작업을 기다리지 않고 끝나 버려서 **[지금 멈추기]가 듣지 않습니다.** 예약을 한 번 다시 추가하면(기존 것을 덮어씀) 고쳐집니다.

### 지정 시각에 PC가 잠자기 중이라면

예약 화면의 **‘절전 중이면 PC를 깨워서 실행’** 을 켜면 작업 스케줄러가 자는 PC를 깨워 실행합니다. 다만 Windows 전원 정책의 **‘절전 모드 해제 타이머 허용’** 이 꺼져 있으면 깨어나지 않습니다(기본값이 꺼짐인 PC가 많음). 체크박스를 켜면 앱이 현재 값을 **읽어서** 확인하고, 꺼져 있으면 실행할 명령을 안내합니다 — 전원 설정 변경은 사용자가 직접 합니다:

```powershell
powercfg /SETACVALUEINDEX SCHEME_CURRENT 238C9FA8-0AAD-41ED-83F4-97BE242C8F20 BD3B718A-0680-4D9D-8AB2-E1D2B4AC806D 1
powercfg /SETDCVALUEINDEX SCHEME_CURRENT 238C9FA8-0AAD-41ED-83F4-97BE242C8F20 BD3B718A-0680-4D9D-8AB2-E1D2B4AC806D 1
powercfg /SETACTIVE SCHEME_CURRENT
```

- **깨우기를 안 켜도** 놓친 예약은 사라지지 않습니다 — 다음에 PC를 켤 때 자동으로 실행됩니다(`StartWhenAvailable`). 대신 사용 중에 갑자기 시작될 수 있습니다.
- PC가 **완전히 꺼져 있으면**(종료·최대 절전 일부 기종) 깨우지 못합니다. 이 경우도 다음 부팅 때 밀린 예약이 실행됩니다.
