# KNOU 강의 이수 + 예습 노트

방송대(KNOU) 강의를 **자동으로 이수**하고, 강의 음성·강의록·영상 화면으로 **예습 노트(옵시디언 마크다운)** 를 만들어 주는 **Windows 데스크톱 앱**입니다. 모은 문제와 기출문제로 **복습 퀴즈**를 풀고, 목표일까지의 **진도**를 관리할 수 있습니다. 명령창을 몰라도 창에서 클릭으로 씁니다.

- 🎬 **이수**: 강의 영상 자동 시청, 영상 중 돌발퀴즈 응답, 형성평가(연습문제) 자동 풀이
- 📝 **예습 노트**: 개념마다 쉬운 설명·예시·🎬 영상 위치·강의 슬라이드 그림. 코딩 실습이 있는 강의는 단계별 완성 코드와 실습 화면까지
- 🧩 **퀴즈**: 돌발퀴즈·형성평가·기출문제를 모아 반복 풀이. 틀린 것부터 다시, AI 해설과 되묻기
- 📈 **진도**: 목표일까지 모든 강의를 한 번씩 보기 위한 트래커
- ⏰ **예약**: 정해진 시각에 자동 실행(앱이 꺼져 있어도, 창 없이)

> [!WARNING]
> **개인 학습용 도구입니다. 반드시 본인 방송대 계정으로만 사용하세요.**
> '이수'·'전체' 모드는 **실제 방송대 서버에 시청 기록을 남기고 돌발퀴즈·형성평가 답안을 제출**합니다. 본인 계정에 반영되며 되돌릴 수 없어서, 앱이 실행 전에 확인 창을 띄웁니다. 처음에는 서버에 아무것도 남기지 않는 **'요약' 모드**부터 써 보세요.

## 🚀 빠른 시작

### 1. 설치 (처음 한 번)

1. [python.org](https://www.python.org/downloads/) 에서 파이썬을 설치합니다. 설치 첫 화면 맨 아래 **"Add Python to PATH"** 를 꼭 체크하세요.
2. 이 폴더의 **`install.bat`** 을 더블클릭합니다. 필요한 것을 알아서 설치하고, "설치 완료!" 가 보이면 끝입니다.
3. (선택) **ffmpeg** 를 설치합니다. 노트에 슬라이드 그림을 넣거나 MP3 가 없는 과목의 음성을 영상에서 뽑을 때 필요합니다. 없어도 글로 된 노트는 만들어집니다.

   ```powershell
   winget install Gyan.FFmpeg
   ```

   winget 이 없으면 [ffmpeg.org](https://ffmpeg.org/download.html) 에서 받은 `ffmpeg.exe`·`ffprobe.exe` 를 이 폴더에 넣어도 됩니다.

수동 설치와 자세한 안내는 [README_GUI.md](README_GUI.md) 를 보세요.

### 2. 실행

**`run_app.bat`** 을 더블클릭하면 앱이 뜹니다. **설정 → [바탕화면 바로가기 만들기]** 를 누르면 다음부터 바탕화면 아이콘으로 검은 창 없이 켤 수 있습니다.

### 3. 설정

**설정** 탭에서 별표(*) 항목을 채우고 **[저장]** 합니다.

| 항목 | 설명 |
|---|---|
| 아이디 / 비밀번호 * | 방송대 계정 |
| Gemini API 키 * | [Google AI Studio](https://aistudio.google.com/apikey) 에서 무료로 발급 |
| 볼트 경로 * | 노트를 저장할 옵시디언 볼트 폴더 |
| 요약 폴더 | 볼트 안에서 노트를 둘 폴더(기본 `방송대`) |
| 재생 배속 | 이수할 때 영상 배속(기본 2배) |

이제 **실행** 탭에서 강의를 골라 돌리거나, **예약** 탭에서 자동 실행을 걸면 됩니다.

> AI 모델은 예고 없이 닫히거나 붐빕니다. 그러면 앱이 다음 모델로 저절로 넘어갑니다. 특정 모델로 고정하려면 `.env` 에 `GEMINI_MODEL=gemini-3.5-flash` 처럼 한 줄을 더하세요.

## ▶️ 실행

### 모드

| 모드 | 하는 일 | 서버 기록 |
|---|---|---|
| **요약** | 강의록·MP3 받기 → 예습 노트 → 슬라이드 그림 붙이기 | 남지 않음 |
| **이수** | 영상 시청 + 돌발퀴즈 + 형성평가 자동 풀이 | **남음**(확인 창) |
| **전체** | 이수 + 요약 | **남음**(확인 창) |

요약 모드는 슬라이드 그림을 뽑을 영상 주소만 받아 오고, 영상을 재생하지 않습니다. 그래서 플레이어 창이 뜨지 않고 진도 기록도 남지 않습니다.

### 부분 실행

| 단추 | 쓰는 때 |
|---|---|
| **[영상 이수만 실행]** | 노트는 있는데 이수만 안 된 차시. 노트를 다시 만들지 않습니다 |
| **[형성평가만 실행]** | 형성평가만 다시 풀어 문항을 모을 때. 서버 제출이라 확인 창이 뜹니다 |
| **[강의록만 받기]** | 강의록 내려받기가 실패한 차시. 현황 탭의 내려받기 아이콘으로도 됩니다 |

### 한 번에 몇 강

- **차시를 고르면** 그 한 강만 돕니다.
- **차시를 비우면** '한 번에 최대 N강' 만큼 차례로 돕니다. '미이수부터' 를 켜면 아직 안 본 차시만 대상으로 삼습니다.
- 예약은 기본값 **3강**을 권합니다. 15강을 한 번에 이수하면 12시간 넘게 걸립니다.

### 실패하면 이어서

단계마다 성공 여부가 `state.json` 에 기록됩니다. 다시 실행하면 **성공한 단계는 건너뛰고 실패한 단계부터** 이어서 합니다. 한 단계가 실패해도 그 결과물이 필요 없는 다음 단계는 그대로 진행합니다. 전부 처음부터 하려면 **[이미 만든 것도 다시 만들기]** 를 켜세요.

강의 목록(`lectures.json`)은 실행이 끝날 때마다 저절로 갱신됩니다. 수강 과목이 바뀌었을 때만 **[목록 새로고침]** 을 누르면 됩니다.

## 📝 예습 노트

강의 MP3 와 강의록(PDF)을 Gemini 에 보내 노트를 만들고, 영상에서 슬라이드 화면을 뽑아 개념마다 붙입니다.

- 개념마다 **쉬운 정의 · 왜 필요한가 · 직관/예시 · 헷갈리기 쉬운 점**을 2~4문장씩 풀어 씁니다. 끝에 **한눈에 정리**와 **예습 체크리스트**가 붙습니다.
- 개념 제목 아래 `🎬 [HH:MM:SS]` 로 영상에서 그 개념이 시작하는 위치를 적습니다.
- 슬라이드 그림은 1초 간격 화면에서 겹치는 장면을 걸러 슬라이드 묶음을 만들고, AI 가 개념마다 맞는 슬라이드를 고릅니다. 노트 시각에서 멀리 떨어진 슬라이드(강의 끝 '정리하기' 등)는 고르지 않습니다.
- 그림은 볼트의 `_captures` 폴더에 두고 `![[그림.jpg|695]]` 처럼 폭을 정해 넣습니다.

### 코딩 실습이 있는 강의

오픈소스기반데이터분석처럼 슬라이드 설명 뒤에 강사가 Colab 노트북의 빈칸을 채우며 코드를 실행하는 강의는, 노트를 **이론과 실습으로 나눠** 씁니다.

- **이론**: 다른 강의와 같은 방식으로 씁니다.
- **실습**: 강의의 **빈칸 실습 노트북**(공개 저장소)과 **강사가 코드를 치는 화면**(최대 90장)을 함께 넘겨, 단계마다 🎬 위치·하는 일·**완성 코드**·실행 결과를 씁니다. 단계 번호와 제목은 노트북을 따릅니다.
- 실습 단계에는 강사가 다음 칸으로 넘어가기 직전, **코드가 다 채워진 화면**을 AI 가 골라 붙입니다.
- 화면에 보이는 API 인증키는 노트에 옮기지 않고 `[발급받은 인증키]` 로 가립니다.

실습 자료가 있는 과목과 저장소는 `practice.py` 의 `PRACTICE_SOURCES` 에 적습니다.

### 과목마다 다른 점

| 경우 | 처리 |
|---|---|
| **MP3 링크가 없는 과목**(AI네이티브 등) | 영상에서 음성만 뽑아 같은 품질로 만듭니다. 그것도 안 되면 강의록만으로 만들고, 근거가 없는 🎬 위치는 넣지 않습니다 |

| **바이오통계학** | `knouon.knou.ac.kr` 에서 돌아가며 차시 대신 주차입니다. MP3 가 없어 강의 슬라이드로 노트를 만듭니다(도구 탭 → '바이오통계학 슬라이드 받기' → '손에 있는 강의록 들여오기'). 형성평가와 슬라이드 캡처는 아직 지원하지 않습니다 |
| **강의록 다운로드가 통째로 실패한 과목** | 따로 모아 둔 강의록 폴더를 도구 탭 → '손에 있는 강의록 들여오기' 로 들여옵니다 |

## 🧩 퀴즈

이수할 때 푼 **돌발퀴즈·형성평가**는 정답·해설과 함께 볼트의 `퀴즈` 폴더에 저장됩니다. 강의자료실의 **기출문제와 정답표**로 문제은행도 만들 수 있습니다(퀴즈 탭 → [기출 더 가져오기]).

- **풀이 기록**이 남아 **틀린 것부터** 다시 나옵니다. 출제 모드는 [전체] · [오답만] · [안 푼 것만] · [복습할 것] 입니다.
- 문항마다 **'안 푼 문제' · '3번 풀어 2번 맞힘'** 같은 표지가 붙습니다.
- **[왜 이게 정답인지 설명 보기]** 로 AI 해설을 받습니다. 한 번 만든 해설은 저장됩니다.
- 해설을 읽고도 막히면 **되물을 수 있습니다.** 창이 넓으면 대화가 오른쪽 판에 붙어 문제를 보면서 묻고, 대화도 저장됩니다.
- **'N강 모아보기'** 로 회차를 가리지 않고 그 강의 문항만 모읍니다.
- 창이 작으면 위쪽 메뉴가 한 줄로 접혀 문제가 크게 보입니다. [메뉴 펼치기]·[메뉴 접기] 로 바꿉니다.
- **[HTML로 저장]** 하면 어디서나 열리는 단일 페이지(`강의퀴즈.html`)가 만들어집니다.

### 기출문제

- 시험지 PDF 를 쪽마다 이미지로 읽어 문항을 만들고, 정답표 HWP·PDF 에서 그 과목·회차의 정답을 붙입니다. 정답표 표기가 불분명한 자리는 정답을 비워 둡니다.
- **기출 원본**: 퀴즈 탭의 '기출 원본' 줄에서 회차마다 **[시험지] [정답표]** 를 눌러 원본 파일을 엽니다. PDF 정답표는 그 과목 줄이 있는 쪽만 잘라 노랗게 칠해 엽니다.
- **변형 문제**: 개념은 그대로 두고 숫자·코드만 바꾼 문제를 따로 만듭니다. C 코드 문항은 실제로 컴파일·실행해 정답을 확인합니다(C 컴파일러 필요: `install_compiler.bat`).
- 문항 확인·바로잡기, 그림 붙이기, 강 번호 붙이기 같은 정비 작업은 **도구** 탭에 있습니다.

## 📈 진도

목표일까지 **모든 강의를 한 번씩 보는 것**을 돕는 트래커입니다. 과목마다 1~15강 칸을 눌러 들은 강을 표시합니다.

- 머리말에 **D-day · 본 강의 수 · 하루/주 몫**(예: `D-49 · 11 / 75강 · 하루 1~2강 · 주 10강`)과 오늘·이번 주에 본 양이 나옵니다. 차질이 생기면 남은 강의를 남은 날로 다시 나눕니다.
- 계획보다 뒤처졌으면 경고와 함께 어느 과목부터 볼지 알려 줍니다.
- 과목 카드마다 **최근 인증한 날**(예: `9/20(일) · 14일 전`)을 적고, **가장 오래 손을 놓은 과목을 맨 위**에 '다음 차례 · 4강' 표와 함께 둡니다.
- 주마다 몇 강 봤는지 막대로 보여 줍니다.
- 단톡방에 올린 공부 인증은 도구 탭 → **'카카오톡 인증 기록 불러오기'** 로 한꺼번에 채웁니다(대화 내보내기 `.txt`). 이미 적힌 날짜는 덮어쓰지 않습니다.

## 📊 학습 현황

**현황** 탭에서 과목별 표 한 장에 차시마다 다음을 나란히 봅니다. **[HTML로 저장]** 하면 `학습현황.html` 로도 남깁니다.

| 열 | 내용 |
|---|---|
| 차시 | 번호 · 제목 · 시청 진도 |
| 영상이수 | 완료 / 실행함(목록 갱신 전) / 실행했지만 서버는 미완료 |
| 형성평가 | 영상이수와 같은 표시 + 문항 수 칩(누르면 퀴즈로). 형성평가가 없는 차시는 회색 '없음' |
| 예습노트 · MP3 · 강의록 | 누르면 각자 알맞은 곳에서 열립니다 |

- **[남은 것만 보기]** 로 아직 안 끝난 차시만 봅니다. 과목 칩으로 과목을 바로 바꿉니다.
- 예습 노트는 **옵시디언**에서, 강의록 PDF 는 **앱 안 뷰어**에서, MP3 는 윈도우 기본 프로그램에서 열립니다.

## ⏰ 예약과 절전

- 예약은 Windows 작업 스케줄러에 등록되어 **앱이 꺼져 있어도** 지정 시각에 창 없이 실행됩니다.
- 실행 중에는 **유휴 절전을 막습니다.** 다만 노트북 **뚜껑을 닫으면** 그래도 잠듭니다. 뚜껑을 닫고 돌리려면 전원 옵션에서 '덮개를 닫을 때' 를 **아무 것도 안 함** 으로 바꾸세요.
- **'절전 중이면 PC를 깨워서 실행'** 을 켜면 자는 PC를 깨웁니다. Windows 의 '절전 모드 해제 타이머 허용' 이 꺼져 있으면 앱이 켜는 명령을 안내합니다(설정 변경은 직접 합니다).
- 놓친 예약은 다음에 PC를 켤 때 실행됩니다.
- **[지금 멈추기]** 는 돌고 있는 실행을 즉시 멈추고, **[끄기]** 는 다음 실행부터 막고, **[삭제]** 는 예약을 지웁니다.

## 🔒 안전과 개인정보

- 비밀번호와 API 키는 **`.env` 에만** 저장합니다. 화면에서는 가리고, 로그·콘솔·명령 인자에 평문으로 남기지 않습니다.
- 영상 주소에 든 시한부 토큰과 학번은 파일·로그에 저장하지 않습니다.
- `.env`, 로그, 내려받은 자료, 캡처 이미지 같은 개인 자료는 git 에 올라가지 않습니다.
- 이수·전체 모드와 형성평가만 실행은 되돌릴 수 없는 서버 기록을 남기므로 항상 확인 창을 거칩니다.
- **로그인**: 학교 로그인 화면의 '(구)로그인' 으로 들어가고, 그것이 닫히면 새 아이디 로그인으로 넘어갑니다. 학교가 이메일·앱 인증번호 같은 **추가 인증**을 요구하면 자동 로그인은 멈추고 그 사실을 실행 기록에 남깁니다.

## 👩‍💻 개발

**기술 스택**: Python 3 · [Flet](https://flet.dev) 0.85(데스크톱 GUI) · [Playwright](https://playwright.dev)(브라우저 자동화) · [Google Gemini](https://ai.google.dev)(`google-genai`) · PyMuPDF · olefile(HWP) · ffmpeg · Windows 작업 스케줄러

GUI 는 명령줄 백엔드(`main.py`)를 하위 프로세스로 돌리는 껍데기라, 명령줄로도 그대로 씁니다.

```bash
python main.py --mode 요약 --course 자료구조 --seq 3
python main.py --mode 요약 --course 자료구조 --seq 1 --stages extra   # 두 번째 영상 노트
python main.py --mode 이수 --unwatched --limit 3
```

| 옵션 | 뜻 |
|---|---|
| `--mode` | `요약` · `이수` · `전체` |
| `--course` · `--seq` | 과목(부분 일치) · 차시 |
| `--unwatched` · `--limit` | 미이수만 · 한 번에 최대 N강 |
| `--stages` | 특정 단계만(`download` `summarize` `capture` `watch` `exam` `extra`) |
| `--force` | 이미 끝난 단계도 다시 |

**주요 모듈**

| 파일 | 역할 |
|---|---|
| `main.py` | 실행 오케스트레이션(단계·이어서 하기·상태 기록) |
| `auth.py` · `discover.py` · `knouon.py` | 로그인 · 강의 목록 · 바이오통계학(knouon) |
| `watch.py` · `exercise.py` | 영상 이수 · 형성평가 |
| `download.py` · `summarize.py` · `practice.py` | 자료 받기 · 노트 생성 · 실습 자료 |
| `capture.py` · `deck_match.py` | 영상 주소 · 슬라이드 묶음과 개념 대조 |
| `quiz_*.py` · `exam_*.py` · `build_exam_bank.py` | 퀴즈 · 기출 은행 |
| `study_plan.py` · `kakao_log.py` | 진도 트래커 · 카카오톡 인증 |
| `app/views/*.py` | 탭별 화면 |

학교 사이트 구조(셀렉터, 요청, 진도 적립 방식)는 [`docs/lms-map.md`](docs/lms-map.md) 에 정리되어 있습니다.

**테스트**

```bash

```
